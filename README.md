# Python Task 4 – HackerRank Coding Practice

## About the Project
This project contains 20 Python programming solutions for HackerRank practice problems. Each solution is saved in a separate Python file.

## Folder Structure
```text
Task_4/
├── problem1.py
├── problem2.py
├── problem3.py
├── ...
├── problem20.py
└── README.md
```

## Files Included
- `problem1.py` to `problem20.py` contain the solutions to the assigned problems.
- Each Python file includes the problem name and HackerRank problem link as comments at the top.

## How to Run
1. Install Python 3 on your computer.
2. Open a terminal or command prompt inside the `Task_4` folder.
3. Run an individual solution using:

   ```bash
   python problem1.py
   ```

4. Replace `problem1.py` with the required filename to run another solution.
5. Enter the input required by the problem, if prompted.

## How to Submit
1. Open the corresponding problem on HackerRank.
2. Copy or upload the solution code and test it using the problem's test cases.
3. Submit the solution on HackerRank and confirm that it is accepted.
4. Upload the Task 4 files to your public GitHub repository under:

   `Internship_Tasks/Python_Tasks/Task_4/`

5. Compress the complete `Task_4` folder into a ZIP file named `Task_4.zip`.
6. Upload `Task_4.zip` to the Learning Management System (LMS), as instructed.

## Important Notes
- Keep all 20 Python files in the `Task_4` folder.
- Do not remove the problem names or HackerRank links from the files.
- Test each solution before submission.
- Ensure the GitHub repository and ZIP file contain the correct Task 4 files.
